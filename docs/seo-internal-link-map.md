## Page-level rule

Each priority article should contain, where relevant:

1. One link to its primary guide.
2. One link to a supporting article or adjacent operational topic.
3. One proof link to a case study when the claim is supported there.
4. One conversion link, without repeating the same CTA throughout the body.
